# Data Science Fundamentals Assessment

## Contents
| File | Purpose |
|---|---|
| `Data_Science_Fundamentals.ipynb` | Main notebook with code, outputs and explanations |
| `data/` | Sample CSVs and saved plots generated by the notebook |
| `requirements.txt` | Libraries needed |

## Topics covered
1. Data Science lifecycle, types of analysis, industry use cases
2. Python basics: variables, data types, operators, conditions, loops, functions, lists, tuples, dicts, sets, file handling
3. Statistics: mean, median, mode, variance, std, percentiles, probability, correlation
4. Data types and structures: numerical, categorical, ordinal, datetime, text
5. Best practices: clean code, reproducibility, validation, documentation, responsible interpretation
6. Five practical assignments on a student dataset

## Run
```bash
pip install -r requirements.txt
jupyter notebook Data_Science_Fundamentals.ipynb   # Kernel -> Restart & Run All
```
